# Google Play listing assets

These files use Google Play's required dimensions and can be uploaded as an
initial listing set:

- `app-icon-512.png` — 512 × 512 app icon.
- `feature-graphic-1024x500.png` — 1024 × 500 feature graphic.

The high-resolution Nyx icon source is kept at
`assets/ui/nyx-app-icon-source-v1.webp`; the feature graphic overlay source
remains in `source/` so the branding is easy to revise.
Before production release, review these at phone size and replace them if the
final Fifth Echo brand direction changes.

Google Play also requires real screenshots from the app. Capture at least two
phone screenshots after installing the APK on a physical Android device; good
choices are one full combat scene and one reward/shop screen. Do not create
fake screenshots from the feature graphic.

Suggested short description (70 characters):

> Build a party, master five lives, and break five collapsing realities.
